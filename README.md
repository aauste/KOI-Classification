# KOI Classification
##### Data: https://exoplanetarchive.ipac.caltech.edu/cgi-bin/TblView/nph-tblView?app=ExoTbls&config=cumulative
NASA Exoplanet Archive contains the Kepler Objects of Interest data, which identifies objects as possible planets for further vetting. This project aims to produce a robust classification ML model, capable of identifying planets based on given Kepler data, created for studying purposes.
